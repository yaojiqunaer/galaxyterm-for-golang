## 功能特性

<details>
  <summary><b>🕸 远程终端ssh连接</b></summary>
  提供安全可靠的远程ssh访问
</details>

<details>
  <summary><b>🔗 远程文件访问</b></summary>
  支持直接选择已保存的 SSH 连接浏览、编辑、上传和下载远程文件；二进制和大文件使用原生文件选择器与流式传输，不经过 WebView 文本内存。无需重复填写 Host、端口、账号和主机身份校验配置，系统凭据仅在执行操作时按需解析。
</details>

<details>
  <summary><b>可插拔文件协议</b></summary>
  文件工作区由主程序统一提供，SFTP、FTP、S3 及后续 WebDAV 等协议通过 `.gtx` 扩展接入。扩展只实现协议和认证适配，复用统一的文件浏览、传输、凭据引用、错误处理和审计体验，避免把各协议 SDK 打进基础安装包。
</details>

<details>
  <summary><b>🔀 SSH 端口转发</b></summary>
  支持复用已保存的 SSH 连接创建本地端口转发，并兼容密码、私钥、私钥口令和 SSH Agent 认证；未保存凭据时可输入仅供本次使用的密码或私钥。转发规则可保存、搜索、编辑、复制、删除并一键启动，也可以从 SSH 连接菜单或详情直接创建；规则只记录连接引用和两端地址，不保存密码、私钥等凭据。运行中、连接缺失、需要凭据和保活失败状态会分别显示。端口转发复用连接的认证、连接超时、SSH 保活与主机身份校验策略，不会绕过 SSH 安全检查。
</details>

<details>
  <summary><b>🗂 连接管理与系统凭据</b></summary>
  SSH 连接可保存 1 至 120 秒连接超时及可选保活间隔/连续失败上限；终端、连接检测和端口转发复用这些设置，SFTP 复用连接超时。导入 OpenSSH Config 时会读取 `ConnectTimeout`、`ServerAliveInterval` 和 `ServerAliveCountMax`。
  保存连接支持最多 12 个标签；标签可跨分组复用，并参与连接列表筛选、全文搜索和命令面板检索。多选连接后可批量添加、创建或移除标签，操作不会中断活动会话。连接配置导入导出会保留标签，旧配置无需迁移即可继续使用。
  支持保存 SSH 连接名称、分组、Host、端口、账号、认证方式、Agent Socket、主机密钥策略、Known Hosts 路径和跳板机等非敏感配置；新建和编辑时可选择只保存，或保存后立即打开终端。密码、私钥之外，macOS/Linux 也可直接使用运行中的 SSH Agent；Socket 留空时读取 `SSH_AUTH_SOCK`，私钥不会进入 GalaxyTerm，Agent 连接可被终端、连接检测、SFTP 和端口转发复用。默认使用“接受新主机”策略：首次连接将密钥写入 GalaxyTerm 受保护的 `known_hosts` 文件，之后密钥变化会被拒绝；严格模式只允许文件中已有的主机，也可指定自定义文件。终端、连接检测、跳板机、SFTP 和端口转发复用同一策略。密码、私钥、私钥口令和跳板机密码可写入系统凭据库，连接配置和导出文件只保存凭据引用。连接管理页支持收藏优先、分组概览、打开收藏和按分组批量打开；勾选连接后可批量打开、检测、移动分组、收藏、导出或删除，`Space` 勾选当前项、`Cmd/Ctrl+A` 选择当前筛选结果、`Esc` 清除选择。连接检测按需复用 SSH、扩展终端或文件协议的探测能力，不创建会话，也不写入审计或录屏；SSH 首次检测可能按上述策略记录主机密钥。列表和详情会显示本次应用运行期间的延迟或脱敏错误，配置或凭据变化后自动清除旧结果。批量删除会明确展示连接、保存凭据和活动会话的影响，删除配置不会关闭已打开的会话。分组菜单可在组内新建连接、重命名或安全解组，连接菜单可直接移动到已有或新建分组。重命名到已有分组会合并，解组只会把连接移到“未分组”，不会删除配置、凭据或活动会话。也可通过系统文件选择器读取并预览 OpenSSH Config 后批量导入连接；`IdentityAgent` 会导入为 Agent 认证，显式 `IdentityFile` 仍优先。已有活动会话时，主操作会定位现有会话，同时保留明确的新建终端入口；列表支持方向键定位、`Enter` 打开或定位，以及 `Shift+Enter` 新开。连接准备期间，列表、详情和侧栏会同步显示加载状态，同一连接的重复点击会被安全合并，其他连接仍可并行打开。侧栏快速连接可用键盘直接打开，并通过行尾按钮或右键菜单编辑、复制、收藏、新开或删除保存连接。
</details>

<details>
  <summary><b>统一命令面板</b></summary>
  命令历史按终端类型、会话和命令精确隔离，同一命令在不同会话中不会互相覆盖；可删除单条记录，并在安全设置中暂停本地历史记录或设置 20 至 500 条的保留上限。该设置不改变审计和录屏行为。
  命令面板可统一搜索连接、活动会话、终端类型、快捷命令和工作区页面；最近成功执行的操作会优先显示，只记录动作标识，不保存命令内容、连接凭据或会话数据。结果列表支持方向键、`Home`、`End`、`Enter` 和 `Esc`，键盘选中项会自动滚入可见区域；不可执行的操作会保留在结果中并说明当前缺少的条件。统一命令中心通过标签切换快捷命令与命令历史，原有快捷键和菜单仍可直达对应标签；两处都会展示当前目标和就绪状态。快捷命令可按当前终端类型、全部或收藏筛选，历史可按类型、会话或全部筛选；可向已连接且空闲的终端直接运行命令，也可先填入单行命令供用户检查和修改后再执行。多行命令不会伪装成安全填入，新建和编辑表单按需展开。所有入口共用敏感命令门禁，旧数据中的密码、Token、私钥路径或 Bearer 凭据不会从命令中心或命令面板发送。
</details>

<details>
  <summary><b>🧾 审计日志与终端录屏</b></summary>
  记录会话打开、重连、关闭、错误、清屏、快捷命令和大段粘贴等操作事件；终端输出会保存为 asciinema v2 文本录屏。审计页使用只读 xterm 按原始时间戳还原 ANSI 颜色、回车覆盖、清屏和光标移动，支持播放、暂停、重播、拖动进度、逐事件跳转和倍速播放，并可导出 `.cast` 或 `.log`。活动会话可随时保存快照，同一连接段重复保存会更新原记录；关闭会话、重连或退出应用会最终保存完整录屏，重连后的输出作为同一会话下的新连接段保留。本地审计存储空间不足时会从最旧记录开始清理；若本次录屏仍无法保存，会保留已有历史、明确提示原因，并且不会阻塞会话关闭。
</details>

<details>
  <summary><b>🔐 敏感信息脱敏</b></summary>
  保存和导出审计记录、录屏时会对常见密码、Token、Authorization 头、私钥块等内容做基础脱敏；升级后读取旧记录时也会自动清洗历史元数据和录屏事件。默认不记录每个按键原文，只记录输入摘要和输出录屏。
</details>

<details>
  <summary><b>⏱ 命令执行状态与中断</b></summary>
  交互式终端会展示当前命令、实时耗时和运行状态；运行期间可通过工具栏、中断按钮或 `Ctrl+C` 发送标准 PTY 中断。Shell 提供 OSC 133 集成时会同时展示真实退出码，常见 Shell、PowerShell、MySQL、Redis 和 PostgreSQL 提示符可用于识别命令完成。
</details>

<details>
  <summary><b>多会话批量命令</b></summary>
  可从会话工具栏或会话菜单将一条命令发送到多个终端。目标只包含已连接且空闲的会话，默认仅选中当前会话，用户必须明确选择至少两个目标；忙碌、连接中、异常或已关闭的会话会自动排除。批量发送仅接受单行命令，并拦截常见密码、Token、私钥等敏感内容；每个成功发送的目标仍独立进入命令历史、审计和终端录屏，局部失败不会向已成功的会话自动重发。
</details>

<details>
  <summary><b>终端输出搜索</b></summary>
  在当前终端中输入关键词后即时高亮全部匹配，并显示当前位置和匹配总数；支持区分大小写、全词匹配和正则表达式，非法正则不会中断终端并会明确提示。`Enter` 跳到下一个，`Shift+Enter` 返回上一个，`Esc` 清除搜索并把输入焦点交还终端。切换会话时会在目标终端重新执行当前查询，后台输出新增匹配后也会自动刷新，结果不会串到其他会话。滚回历史输出后可一键回到最新内容；终端中的 HTTP(S) 链接需要按住 `Cmd` 或 `Ctrl` 点击才会在系统浏览器打开，避免误触和危险协议。
</details>

<details>
  <summary><b>多会话保护与工作区连续性</b></summary>
  标签右键菜单支持关闭当前标签左侧或右侧的会话；受保护会话始终保留，其他会话在关闭前完成审计落盘。
  每个终端标签可独立保护，受保护会话会显示锁标识、隐藏标签关闭按钮，并在“关闭全部”“关闭其他”和“关闭已关闭会话”时保持打开。保护状态会随工作区快照保存和恢复；恢复会按数量复用已经打开的同类会话，只创建缺少的标签，重复执行不会不断追加副本。保存连接产生的远程会话可通过系统凭据库安全重建，临时远程会话、缺失 Provider 或凭据不可用的会话会明确跳过；关闭最后一个标签后，自动保存会清除旧快照，避免下次启动重新打开用户已主动关闭的会话。在连接、文件、审计或设置页面之间切换不会卸载终端，只有明确关闭标签才会结束对应会话。`Ctrl+Tab` 会打开不抢焦点的最近使用会话切换层，重复按键循环选择，松开 `Ctrl` 确认，`Esc` 取消；名称、连接目标、运行状态和未读活动会同时呈现。会话侧栏始终保留与标签栏相同的稳定顺序，异常或已关闭标签不会消失；会话较多或存在异常时，可按全部、运行、异常分段筛选，并继续按名称、类型、主机、用户或目录搜索。行尾按钮和右键菜单可执行重命名、保护、重连、复制、移动和关闭操作，过滤状态下会暂停拖拽重排以避免隐藏项造成顺序误判。所有重连入口共享即时进度与去重保护；同一会话在重连完成前只发起一次连接，旧连接段的迟到状态不会覆盖当前终端。会话工具栏、全局会话菜单和命令面板会在存在异常或已断开标签时提供批量重连；该操作按标签顺序恢复目标，只汇总一次结果，并保持当前页面、活动标签和终端焦点不变。安全设置可为保存过的远程连接启用异常自动重连，首次延迟和最多尝试次数可配置，后续按指数退避并限制在 30 秒内；普通退出、本地终端和临时连接不会触发。终端状态栏展示倒计时、当前次数、取消和重试耗尽状态，后台重连不会切换当前标签或页面；每次尝试会结束上一段审计与录屏并记录新的自动重连事件。重名会话会自动显示序号，并在标签、侧栏、窗口标题和命令面板中保持一致；可从会话工具栏、菜单或命令面板安全复制 `user@host:port` 或本地工作目录，凭据不会进入剪贴板。未指定目录的本地终端从用户主目录启动，并以 `~` 作为可复制会话目标。
</details>

## 架构

核心程序只保留本地终端、SSH、会话管理、通用文件工作区、凭据和扩展宿主。终端扩展与文件协议扩展分别声明 `providers` 和 `fileProviders`，可通过 GitHub Releases 在线获取或使用 `.gtx` 包离线安装。扩展管理支持按名称、Provider、能力和状态搜索；保存连接缺少对应 Provider 时可直接定位扩展安装或启用入口，停用或卸载前会展示受影响的连接和活动会话。每个活动终端会在状态栏标明由核心还是扩展提供；扩展被停用或卸载后，已打开会话保持到用户关闭，同时状态会明确告知新会话是否可用，点击扩展状态可直接定位管理页面。审计和录屏状态同样可点击并进入当前会话记录。文件协议扩展支持按能力声明 `list`、`read`、`write`、`upload`、`download`、`mkdir`、`rename`、`delete` 等操作，并通过 `configFields`、`authFields` 贡献连接表单；文件位置可保存到统一连接管理中，认证字段进入系统凭据库，连接档案和导出文件不保存明文。界面无需识别具体协议，只展示当前 Provider 实际支持的字段和命令。

扩展源、`galaxyterm-index.json` 与 GitHub Release 发布格式见 [扩展分发文档](docs/extensions.md)。

交互式终端扩展以每会话一个受控 sidecar 进程运行。安装或卸载后可用 Provider 会立即刷新，无需重启应用，也不会中断已经打开的会话；扩展还可在 `.gtx` 内提供隔离命名空间的多语言词典，语言切换和扩展变更后即时生效。协议帧、词典约束、超时和进程生命周期约束见扩展分发文档。

## 安装

### 文件协议扩展

基础安装包不包含 SFTP、FTP 或 S3 SDK。官方 SFTP 扩展可独立构建为 `.gtx` 离线包：

```shell
./scripts/package-extension.sh sftp
```

产物位于 `dist/extensions/`。在“扩展”页面选择“离线安装”，安装后“文件”页面会自动发现 SFTP，并按扩展声明的能力显示浏览、编辑、上传、重命名或删除操作。FTP/FTPS 与 S3 扩展将使用相同的 `stdio-json-v1` 文件 Provider 协议接入，无需修改核心文件工作区。

发布到 GitHub Release 前，可执行 `./scripts/generate-extension-index.sh` 为全部平台包生成在线安装索引。

### 本地启动

```shell
CGO_LDFLAGS='-framework UniformTypeIdentifiers' go run -tags dev .
```
